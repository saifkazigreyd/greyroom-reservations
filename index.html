Backup & restore (most reliable safety net)

Downloads every month, booking, expense, handover, property and access code into one file on your device. This file does not depend on browser storage at all, so it survives anything. Do this at the end of each working day.

Migrate old data

This app now saves to Google Sheets instead of Claude's old storage. If any bookings, expenses, handovers, or months are still sitting in that old storage from before the switch, this pulls them in and merges them into Google Sheets. Safe to run any time — it never deletes anything.

Danger zone

Clears all pending bookings, confirmed bookings, expenses and handovers for the currently selected month only — useful if an Excel import went wrong. Other months, properties and team access are kept. This cannot be undone.
